# 박준유 — Developer Portfolio

박준유의 소개, 학력·교육·수상·자격·병역, 세 가지 프로젝트, 연락처를 담은 정적 포트폴리오입니다.
내용은 제공된 이력과 포트폴리오 텍스트를 기준으로 작성했습니다.

## 구성

- 소개: 개발 방향과 언어·프레임워크·데이터베이스·도구
- 이력: 충북대학교, 남대전고등학교, SSAFY, 수상 2건, 자격 3건, OPIc, 병역
- IDEA2STRATEGY: 시장 데이터 복구, 실시간 시세 전달, 백테스트 데이터 버전 관리
- 멀티모달 졸음 탐지: 기기 연동, 스트리밍 데이터 저장, 얼굴·HRV 특징 융합
- CRYPTO TRACKER: 서버 데이터 캐싱과 클라이언트 상태 분리
- 연락: 이메일·전화·GitHub

프로젝트 도식은 제공된 설명을 바탕으로 HTML/CSS로 작성한 구조 요약입니다.
프로젝트 스크린샷, 모델 성능 그래프, 성적증명서 PDF는 첨부되지 않아 포함하지 않았습니다.
소개에는 신호와 궤도를 표현한 SVG 그래픽을 배치하고, 이력·프로젝트·연락처는 반투명 카드로 구분합니다. 그라데이션·격자·별빛 배경 위에서 문서 전체가 하나의 스크롤로 이어집니다.

## 인터랙션

화면 어디서나 문서 전체를 자연스럽게 스크롤합니다. 소개부터 연락처까지 내용이 순서대로 이어지고, 제목·문단·이력 묶음은 화면 뒤쪽 깊이에 가라앉아 있다가 스크롤 위치에 따라 읽는 평면으로 떠오릅니다. 깊이 이동과 함께 흐림이 걷히며, 완전히 떠오른 내용은 선명하게 유지됩니다.
데스크톱에서는 왼쪽 목록이 고정된 상태로 현재 읽는 섹션을 강조합니다. 클릭·방향키·Home·End로 해당 위치에 이동하거나, 마우스·손가락으로 목록을 위아래로 끌어 페이지를 탐색할 수 있습니다. 드래그는 현재 읽던 위치에서 시작하고 문서의 처음·끝에서 멈추며, 놓으면 가까운 섹션의 시작점에 맞춰집니다.
740px 이하 화면에서는 목차가 헤더 아래의 가로 스크롤 메뉴로 바뀝니다. 메뉴를 좌우로 밀어 항목을 찾고, 누르면 해당 내용으로 이동합니다.
별빛 배경은 Canvas로 그리며 포인터를 따라 미세하게 움직입니다. 화면 크기에 따라 별의 수와 해상도를 제한하고, 탭이 숨겨지면 그리기를 멈춥니다. 기기의 동작 줄이기 설정이 켜져 있으면 배경은 정지하고 내용은 즉시 표시됩니다.

## 파일과 실행

- `dist/index.html`: 이력·프로젝트·연락처
- `dist/style.css`: 반응형 레이아웃과 시각 스타일
- `dist/script.js`: 문서 스크롤 동기화·순차 등장·드래그·이메일 복사
- `dist/depth-reveal.js`: 스크롤 위치와 Z축 깊이·선명도 동기화
- `dist/reel-core.js`: 원통 투영, 섹션 선택, 문서 위치와 드래그 좌표 변환
- `dist/ambient.js`: 별빛·궤도 배경 그리기, 포인터 반응, 모션·탭 표시 상태 관리
- `dist/assets/`: 파비콘과 소개 영역의 `signal-orbit.svg` 그래픽

설치·빌드 없이 정적 HTTP 서버에서 `dist` 폴더를 열 수 있습니다.
ES 모듈을 사용하므로 파일 더블클릭 대신 HTTP로 열어 주세요.
Google Fonts 연결이 없으면 시스템 글꼴로 표시됩니다.
로컬 미리보기 예시: `python -m http.server 4173 --directory dist` 실행 후 `http://localhost:4173`에 접속합니다.

## GitHub Pages 자동 배포

배포 대상 주소: [https://pjy008008.github.io/portfolio/](https://pjy008008.github.io/portfolio/)

공개 저장소 `pjy008008/portfolio`는 GitHub Actions를 통해 GitHub Pages에 배포합니다. `.github/workflows/pages.yml`이 `main`에 push할 때마다 `dist` 폴더를 배포하며, 별도 설치나 빌드 과정은 없습니다. 저장소의 Actions 탭에서 **Deploy portfolio to GitHub Pages → Run workflow**로 직접 실행할 수도 있습니다. 수동 실행(`workflow_dispatch`)도 `main` 브랜치에서만 배포합니다.

배포 작업은 `github-pages` 환경을 사용하고, 앞선 배포가 끝난 뒤 다음 배포를 진행합니다. 사이트를 수정할 때는 `dist` 안의 파일을 변경해 `main`에 push하면 됩니다.

Pages의 배포 소스는 **Settings → Pages → Build and deployment → Source → GitHub Actions**입니다. 배포 진행 상태와 결과는 저장소의 Actions 탭에서 확인할 수 있습니다.
